# Roadmap

Vote with a 👍 on the linked discussion or open a feature request. Order may change with feedback from people
shipping real apps.

## Next
- **App Review rejection analysis** — read a rejection message, map it to the guideline, propose the fix and the reply.
- **Analytics adapters for the growth loop** — Firebase / GA4 export first, so `/shippilot:grow` can read cohorts
  directly.
- **Screenshot localization pipeline** — localized screenshot text with the same limit checks as the store text.

## Later
- iOS device QA (simulator UI review like the Android `mobile-ui-review` skill)
- Audit for more stores (Huawei AppGallery, Samsung Galaxy Store)
- Rating-prompt and review-reply helpers

## Done
- v0.3 — `/shippilot:audit` for any public App Store / Google Play listing; real-run clip; community templates
- v0.2 — six-stage flow, CI/CD release template, `/shippilot:ad-creatives`
- v0.1 — skills, commands, store metadata checker
